## 📖 Overview
This repository preserves historic Persian community voiceovers, texture sharpening mods, and UI enhancement assets for **Stronghold Crusader HD** (by Firefly Studios), organized following the **ParsiSaz 2026 Game Localization Architecture (L10N-STD-2026)**.

---

## 🗂️ Project Structure (L10N-STD-2026)

```
stronghold-crusader1-mods/
├── loc/                           # Decoupled Core Localization Data
│   ├── fa-IR/                     # Persian translation resources
│   └── glossaries/                # Crusader military terminology
├── game_assets/                   # Game Engine Drop-in Directory
│   └── Graphics Mods/             # High-resolution texture sharpening packs
├── HISTORY.md                     # Semantic Versioning Changelog
├── README.md                      # Project documentation
└── LICENSE                        # GNU General Public License v3
```

---

## 🚀 Installation Instructions

1. Backup your existing Stronghold Crusader installation directory.
2. Copy the desired assets from `game_assets/Graphics Mods/` into:
   ```text
   <Stronghold_Crusader_Directory>/
   ```
3. Launch `Crusader.exe` to experience sharpened textures and enhanced medieval visuals.
